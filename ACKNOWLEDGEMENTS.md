# Acknowledgements

Hyper Quick Controls uses Hyper's plugin hooks and built-in command channel.
Broadcast input is provided by a separately installed hyper-broadcast plugin.
The toolbar also adjusts the position of an existing hyper-scripts panel.

- [Hyper](https://github.com/vercel/hyper) — MIT
- [hyper-broadcast](https://github.com/chabou/hyper-broadcast) — MIT
- [hyper-scripts](https://github.com/van-ibm/hyper-scripts) — MIT

These projects are not bundled in this repository and retain their own licenses
and copyright notices. SVG toolbar icons are defined directly in toolbar.js.
